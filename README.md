# DEAR YOU — 나의 오후 한 잔 찾기

GA4 실습용 공용 틀을 바탕으로 만든 DEAR YOU 랜딩페이지입니다. 현재는 검토용 파일이며 GitHub 업로드와 기존 사이트 배포는 하지 않았습니다.

## 들어 있는 기능

- 크림색·네이비의 브랜드 소개와 세 가지 음료 안내
- 시간대 / 맛 / 카페인 선택의 세 가지 질문과 27가지 답변 조합
- 선택에 맞는 취향 결과 페이지
- 1080 × 1350 PNG 카드 저장과 모바일 이미지 열기 대안
- 수업용 개인정보 안내, 실습용 푸터, AI 이미지 표시

브랜드와 메뉴는 기획·개발 단계입니다. 결과는 맛과 음료 방향을 제안하며 효능, 카페인 수치, 개인의 섭취 적합성을 보장하지 않습니다.

## 미리보기 (Mac)

압축을 푼 폴더의 `미리보기.command`를 실행하면 로컬 서버와 브라우저가 열립니다. Python 3가 필요합니다. 브라우저에서 세 가지 답변 → 결과 보기 → 안내 확인 → 완료 → 카드 이미지 저장 순서로 사용합니다. 미리보기를 끝낼 때 터미널에서 Control+C를 누릅니다.

HTML을 파일로 직접 여는 방식은 브라우저에 따라 저장소·이미지 저장 제한이 있으므로 로컬 서버 또는 GitHub Pages에서 확인하세요. 로컬 미리보기 실행이 막히면 폴더에서 `python3 -m http.server 8766 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:8766`으로 접속합니다.

## 데이터 처리

이름·연락처는 묻지 않습니다. 선택 답변은 서버나 주소창으로 보내지 않습니다. 안내에 동의한 시점에 한해 세 개의 고정된 취향 코드가 `sessionStorage`에 잠시 저장되고, result.html에서 읽은 직후 삭제됩니다. 결과 화면을 새로고침하거나 결과 주소로 바로 접속하면 다시 선택하도록 안내합니다. 이미 내려받은 카드는 기기에 남습니다. 현재 외부 분석 태그는 없습니다.

## 수업 파일 보존

`assets/privacy.js`, `assets/track.js`는 받은 ZIP과 바이트 단위로 동일합니다. `cta-main`, `lead-form`, `cta-submit` ID와 기존 이벤트명/위치 값도 유지했습니다. 변경된 취향 선택 처리는 별도 `assets/quiz.js`에서 수행하며, 개인정보 안내는 실제 처리 방식에 맞췄습니다.

- `cta_click`: header / hero / offer
- `nav_click`: header
- `more_click`: hero
- `faq_open`: faq1 / faq2 / faq3 (원본 파일 특성상 여닫기 클릭에서 발생)
- `generate_lead`: 동의 후 결과 화면으로 이동하는 취향 테스트 완료
- `card_download`: 카드 파일 다운로드 요청 (저장 완료를 보장하는 이벤트는 아님)
- `quiz_restart`: 결과 화면의 다시 찾기 버튼
- `page_view`: GA4 연결 후 기본 페이지 조회. result.html 직접 접속도 포함되므로 전환 수는 generate_lead를 기준으로 확인하세요.

GA4 측정 ID가 아직 없어 분석은 작동하지 않습니다. 수업에서 받은 Google 태그를 index.html과 result.html head의 GA4 주석 아래에 넣고, index.html 개인정보 안내의 분석 도구 문구를 실제 설정에 맞춰 수정하세요. 방문/클릭 통계에 답변이나 개인정보를 추가하지 마세요.

## GitHub Pages에 올릴 때

파일의 canonical, OG 주소, robots.txt, sitemap.xml은 기존에 확인된 `jen-sec` 계정의 `https://jen-sec.github.io/`를 기준으로 준비했습니다. 실제 배포 주소가 바뀌면 함께 수정하세요.

1. `jen-sec.github.io` 저장소의 기존 파일 유무를 확인합니다. 기존 웹사이트가 있다면 덮어쓰지 말고 먼저 검토합니다.
2. 폴더 자체가 아닌 안의 index.html, result.html, assets, robots.txt, sitemap.xml, .nojekyll, README.md를 저장소 루트에 업로드합니다. `미리보기.command`는 로컬 확인용이므로 업로드하지 않아도 됩니다.
3. Pages를 main / root로 설정합니다.
4. 사이트와 실제 카드 다운로드를 확인합니다.

사이트 및 업로드한 소스는 공개 대상이 됩니다. 이 파일 제작만으로 공개 배포되지는 않습니다.

## 2026-10-24 사진 반영

승인된 M1은 한 잔 찾기, C는 우리의 일상(상단 영역은 CSS로 숨김), M3는 일상 사진, M5는 브랜드 이야기에 사용했습니다. M5는 240×426 영상 프레임이므로 작은 크기로 배치했습니다. 상단 메뉴는 음료 소개 / 한 잔 찾기 / 우리의 일상 / 브랜드 이야기 / FAQ입니다.

이번 사진 교체 후 파일 경로·섹션 링크·수업 파일 보존을 확인했습니다. 브라우저 사용이 꺼져 있어 최신 사진 배치의 시각 검토는 미완료입니다. 기존 퀴즈와 PNG 저장은 이전 버전에서 실제 동작을 확인했습니다.
